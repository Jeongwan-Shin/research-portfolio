# Jeongwan Shin · Research Portfolio

PDF 25쪽 순서에 맞춘 연구 포트폴리오입니다. 각 페이지의 설명과 원본 슬라이드(도식·표·수식 포함)를 수록하고, 21쪽 정성적 결과 뒤에 기존 주행 영상 8개를 배치했습니다.

- `index.html`: PDF 1–25쪽 순서의 포트폴리오, 21쪽 뒤 영상 8개
- `qualitative.html`: 별도 영상 보기 (기존 주소 유지)
- `portfolio.pdf`: 사용자 제공 원본 PDF
- `slide-01.webp` ~ `slide-25.webp`: 원본 PDF 전체 페이지
- `scene-01.mp4` ~ `scene-08.mp4`: 기존 영상 원본
- `portfolio.js`: 페이지 선택, 슬라이드 확대
- `script.js`: 영상 전환, 필터, 전체 화면

로컬 실행: `python3 -m http.server 8000`

배포: GitHub Pages, `main` 브랜치 루트. 전체 자료 포함 요청에 따라 PDF의 연락처도 원문대로 수록했습니다. 연구 내용과 수치는 제공 자료 기준이며 RaPhy-AD는 ICLR 2027 Submission입니다.
