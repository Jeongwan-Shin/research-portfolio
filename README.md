# Jeongwan Shin · Research Portfolio

PDF 기반 연구 포트폴리오 및 기존 RaPhy-AD 영상 8개. 빌드 불필요 정적 사이트입니다.

## 로컬 실행

```sh
python3 -m http.server 8000
```

## GitHub Pages

이 폴더의 파일 전체를 새 저장소 루트에 업로드합니다. Settings → Pages → Deploy from a branch → main / (root) → Save.

- `index.html`: 소개, 연구 분야, RaPhy-AD, 시뮬레이션, 연구 경험, 연락처
- `qualitative.html`: 영상 8개, 환경 필터, 다운로드, 전체 화면
- `scene-01.mp4` ~ `scene-08.mp4`: 기존 프로젝트에서 사용한 원본 영상
- `style.css`, `script.js`: 공통 스타일과 영상 인터랙션

출처: 사용자 제공 신정완 자기소개서 PDF 및 기존 RaPhy-AD 프로젝트. 수치와 경력은 제공 자료 기준이며 논문은 ICLR 2027 Submission으로 표시했습니다. 개인 전화번호와 자기소개서 원본은 사이트에 포함하지 않았습니다.
